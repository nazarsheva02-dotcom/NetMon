# NetMon

Маленькая программа для Linux: рисует график пинга и джиттера до роутера, Cloudflare, Google (и игрового сервера, если указать), считает потери пакетов, показывает сигнал Wi-Fi и текущий трафик. Подсказывает, где лагает: Wi-Fi или дальше (провайдер). Запоминает инциденты (время, потери, скачки) в `~/netmon_log.csv`.

Нужны только `python3` и `tkinter`. Больше ничего ставить не надо.

## Установка

```
git clone https://github.com/mazik23/netmon
cd netmon
bash install.sh
```

Скрипт поставит tkinter (Arch, Debian/Ubuntu, Fedora), скопирует программу в `~/.local/bin` и добавит ярлык NetMon в меню приложений.

## Запуск

```
python3 ~/.local/bin/netmon.py
python3 ~/.local/bin/netmon.py --server 203.0.113.5 --name Deadlock
```

Параметры: `--server IP`, `--name ИМЯ`, `--iface ИНТЕРФЕЙС` (по умолчанию определяется сам), `--spike МС` (порог скачка пинга, по умолчанию 100), `--log ФАЙЛ`.

Кнопка «Тест скорости» качает файл с Cloudflare и нагружает канал, в игре её не нажимайте.

## Для ИИ-агентов (например, OpenCode)

Чтобы установить: клонируй репозиторий и выполни `bash install.sh` из его папки. Скрипт не меняет системные настройки, кроме установки пакета tkinter (нужен sudo) и копирования файлов в `~/.local`. Не запускай `pacman -Sy` без `-u`.
