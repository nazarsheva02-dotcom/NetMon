# NetMon

Монитор сети для Linux с графическим окном и терминальным режимом.

## Что делает

- Пингует **роутер**, **Cloudflare** и **Google**, а также игровой сервер, если указать его IP.
- Рисует график пинга за последние 120 секунд.
- Считает **джиттер**, **максимальный пинг** и **потери пакетов**.
- Показывает сигнал Wi-Fi в dBm и текущий трафик (вниз/вверх).
- Подсказывает, где проблема: между ПК и роутером (Wi-Fi) или дальше у провайдера.
- Записывает завершённые инциденты в `~/netmon_log.csv`: время, цель, потери, скачки, максимальный пинг, сигнал Wi-Fi и трафик.
- Умеет работать как окно, как живой терминальный дашборд или как разовый отчёт для скрипта.

## Установка

```
git clone https://github.com/nazarsheva02-dotcom/NetMon.git netmon
cd netmon
bash install.sh
```

> Важно: папка называется `NetMon` с заглавными буквами. Если клонировать без `netmon` в конце, заходить нужно через `cd NetMon`. Команда выше сразу создаёт папку `netmon` в нижнем регистре.

Если при `bash install.sh` появляется `No such file or directory` — значит, вы не находитесь в папке проекта. Проверить: `ls install.sh`, перейти: `cd ~/NetMon` или `cd ~/netmon`.

Скрипт:

- при необходимости поставит `tkinter` (нужен только для окна);
- установит команду `~/.local/bin/netmon`;
- добавит ярлык **NetMon** в меню приложений.

Если команда `netmon` не находится, добавьте в `~/.bashrc`:

```
export PATH="$HOME/.local/bin:$PATH"
```

## Запуск

```
netmon                                      # графическое окно
netmon --cli                                # живой дашборд в терминале
netmon --once                               # один отчёт и выход
netmon --server 203.0.113.5 --name Deadlock
netmon --cli --server 203.0.113.5 --name Deadlock
```

## Параметры

| Параметр | Описание |
|---|---|
| `--server IP` | IP или домен игрового сервера (необязательно) |
| `--name ИМЯ` | название сервера в окне и логе |
| `--iface ИНТЕРФЕЙС` | сетевой интерфейс, по умолчанию определяется сам (`wlan0`, `eth0` и т. п.) |
| `--spike МС` | пинг выше этого значения считается скачком (по умолчанию 100) |
| `--log ФАЙЛ` | файл лога инцидентов (по умолчанию `~/netmon_log.csv`) |
| `--cli`, `--terminal` | не открывать окно, работать в терминале |
| `--once` | один замер, отчёт и выход |
| `--no-color` | отключить ANSI-цвета в терминале |
| `--version` | показать версию |

## Горячие клавиши в окне

- **Space** — тест скорости (нагружает канал, не нажимайте в матче).
- **Ctrl+R** — сбросить график и статистику.
- **Ctrl+Q** — закрыть.
- Наведите мышь на график, чтобы увидеть значения всех целей в выбранный момент.

## Как читать диагноз

- **Сеть в порядке** — потерь и сильного джиттера нет.
- **Лагает Wi-Fi** — проблемы уже на участке ПК ↔ роутер.
- **Роутер в порядке, лагает дальше** — локальная сеть чистая, проблема у провайдера или на маршруте.

## Лог инцидентов

Инцидент начинается при потере пакета или скачке пинга выше `--spike` и закрывается после 10 хороших пингов подряд. В `~/netmon_log.csv` пишутся:

`начало, конец, длит_с, цель, потеряно, замеров, скачков, макс_мс, wifi_dBm, вниз_Мбит/с, вверх_Мбит/с`

## Для ИИ-агентов

Установка: клонировать репозиторий и выполнить `bash install.sh` из его папки. Скрипт не меняет системные настройки, кроме установки пакета `tkinter` при необходимости (может понадобиться sudo). Команда запуска — `netmon`, терминальный режим — `netmon --cli`, разовый отчёт — `netmon --once`.
